# ارتقای Momentum به نسخهٔ ۵ — ورود خودکار روی دستگاه شخصی

## قبل از آپلود

1. از Momentum فعلی روی لپ‌تاپ به «تنظیمات ← خروجی پشتیبان» برو و JSON را در جایی خصوصی نگه دار. **این فایل را هرگز روی GitHub عمومی آپلود نکن.**
2. مطمئن شو نسخهٔ فعلی هنوز به مخزن خصوصی `momentum-data` همگام می‌شود. مخزن خصوصی و توکن فعلی تغییر نمی‌کنند.
3. فایل ZIP نسخهٔ جدید را استخراج کن؛ فایل‌های **داخل آن** را در ریشهٔ مخزن عمومی `momentum-app` آپلود و Commit کن، نه خود ZIP را. مسیر `assets/device.js` باید وجود داشته باشد و `index.html` در ریشه بماند.
4. این آپدیت فایل `sw.js` را هم به‌روزرسانی می‌کند تا کش نسخهٔ جدید جایگزین شود.

## فعال‌سازی روی لپ‌تاپ

1. لینک فعلی `https://yckta.github.io/momentum-app/` را باز کن و `Ctrl + Shift + R` بزن.
2. در «تنظیمات ← همگام‌سازی خصوصی با GitHub»، تیک «مرا در این دستگاه به خاطر بسپار (۳۰ روز)» را روشن کن.
3. **عبارت عبور رمزگذاری قبلی** را وارد کن. اگر توکن قبلاً ذخیره شده، فیلد توکن را خالی بگذار.
4. روی «باز کردن اتصال» بزن و وضعیت «همگام است» را بررسی کن. برای اولین اتصال می‌توانی «ذخیرهٔ امن اتصال و همگام‌سازی» را بزنی.
5. صفحه را ببند و دوباره باز کن؛ پس از اتصال اینترنت باید بدون واردکردن عبارت عبور، همگام‌سازی فعال شود.

## فعال‌سازی روی آیفون

1. اپ Momentum را از **آیکون Home Screen** باز کن (ممکن است حافظهٔ آن از Safari جدا باشد).
2. تنظیمات → همگام‌سازی خصوصی. تیک «مرا در این دستگاه به خاطر بسپار (۳۰ روز)» را روشن کن.
3. اگر قبلاً اتصال این نصب ذخیره شده، فقط عبارت عبور رمزگذاری قبلی را وارد کن و «باز کردن اتصال» بزن؛ در غیر این صورت توکن محدود GitHub را هم از Password Manager وارد کن.
4. اپ را کامل ببند و دوباره باز کن. وضعیت همگام‌سازی را بررسی کن.

## نکات امنیتی

- تیک را فقط روی دستگاه شخصی با رمز صفحه یا Face ID بزن. این قابلیت خودش Face ID/Keychain نیست.
- ورود خودکار به معنی ذخیرهٔ محلی کلید قابل استفاده توسط کد سایت است. اگر کسی به پروفایل مرورگر یا اسکریپت اجراشده در دامنهٔ سایت دسترسی پیدا کند، خطر دسترسی به اطلاعات وجود دارد.
- برای خاموش‌کردن: دکمهٔ «خاموش‌کردن ورود خودکار» را بزن. «قفل‌کردن اتصال و حذف ورود خودکار» علاوه بر این، اتصال فعلی را هم می‌بندد.
- پس از ۳۰ روز، پاک‌شدن داده‌های مرورگر یا تغییر پروفایل، باید دوباره رمز وارد کنی.
- وقتی اینترنت نباشد، تسک‌ها محلی می‌مانند؛ برای تأیید ذخیرهٔ ابری منتظر نمایش «همگام است» باش.
- اگر دستگاه گم شد، توکن `momentum-sync` را در تنظیمات GitHub revoke کن. خاموش‌کردن محلی روی یک دستگاه، دسترسی دستگاه دیگر را لغو نمی‌کند.
